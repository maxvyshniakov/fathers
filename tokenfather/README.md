# Tokenfather

Multi-provider agent token usage collector, incremental daily rollup, and lane-attributed reporter for Claude Code,
Codex, and Antigravity / T3 Code. Standard-library Python 3.11+ only.

## Usage

```sh
tokenfather collect
tokenfather report [--since 2026-11-15T22:00Z] [--until 2026-11-17] [--project data-grid] [--json]
```
