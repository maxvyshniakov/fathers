# Security

Report a vulnerability privately through GitHub: this repository's **Security** tab → **Report a vulnerability**.
Please do not open a public issue for one. Include the package, the affected commit, what an attacker controls and the
smallest reproduction you have. The tools are maintained by one person in spare time; expect an acknowledgement within
about a week.

Only the latest commit on `main` is supported. Package-specific scope notes: [lanefather/SECURITY.md](lanefather/SECURITY.md).
